# MCP Tool IDL Parser

A Go-based parser for MCP Tool IDL files that generates Go structs for MCP input and output types.

## Features

- **Multi-tool Support**: Parse multiple MCP tool definitions in a single file
- **Rich Data Types**: Support for `string`, `int`, `int64`, `float64`, and `bool`
- **Pointer Types**: Automatically generate pointer types for non-required fields
- **Go Package Support**: Specify the generated code's package name
- **Code Formatting**: Generated code is formatted with `go/format`
- **Generated File Comment**: Include `DO NOT EDIT` comment to prevent manual modifications
- **Easy Installation**: Install via `go install`

## Installation

```bash
go install github.com/MegcFn/mcp-idl/cmd/parser@latest
```

## Usage

### Basic Usage

```bash
parser <idl-file.mcpdl>
```

### Custom Output Filename

```bash
parser <idl-file.mcpdl> <output-file.go>
```

## IDL Syntax

### File Structure

```idl
go_package = "package_name"

tool mcp__tool__name {
    description "Tool description"
    
    input {
        field_name: type "Field description" [required]
        // More fields...
    }
    
    output {
        field_name: type "Field description"
        // More fields...
    }
}

// Additional tools...
```

### Supported Types

- `string` - String type
- `int` - Integer type
- `int64` - 64-bit integer type
- `float64` - 64-bit floating point type
- `bool` - Boolean type

### Example

```idl
go_package = "example"

tool mcp__test__echo {
    description "Echo back the input message for testing purposes"
    
    input {
        message: string "Message to echo back" required
    }
    
    output {
        result: string "Echoed message"
    }
}
```

## Generated Code

The above IDL will generate the following Go code:

```go
// Code generated by mcpidl. DO NOT EDIT.

package example

type Mcp__test__echoInput struct {
	Message string `json:"message" jsonschema:"Message to echo back"`
}

type Mcp__test__echoOutput struct {
	Result *string `json:"result" jsonschema:"Echoed message"`
}
```

## Filename Convention

- Input file: `<name>.mcpdl`
- Output file (default): `<name>.mcpdlc.go`
