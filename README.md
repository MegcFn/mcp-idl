# MCP Tool IDL Parser

A Go-based parser for MCP Tool IDL files that generates Go structs for MCP input, output, and data types.

## Features

- **Multi-tool Support**: Parse multiple MCP tool definitions in a single file
- **Data Type Definitions**: Define reusable data types with `data` keyword
- **Rich Data Types**: Support for `string`, `int`, `int64`, `float64`, `bool`, `object` (converted to `map[string]any`), and arrays (e.g., `[string]`)
- **Pointer Types**: Automatically generate pointer types for non-required fields
- **Getter Methods**: Generate getter methods for all fields in structs
- **Go Package Support**: Specify the generated code's package name
- **Code Formatting**: Generated code is formatted with `go/format`
- **Generated File Comment**: Include `DO NOT EDIT` comment to prevent manual modifications
- **Recursive Processing**: Support for `./...` and `dir/...` patterns to process multiple files
- **Easy Installation**: Install via `go install`

## Installation

```bash
go install github.com/MegcFn/mcp-idl/cmd/mcpidl@latest
```

## Usage

### Basic Usage

```bash
mcpidl <idl-file.mcp>
```

### Custom Output Filename

```bash
mcpidl <idl-file.mcp> <output-file.go>
```

### Process All Files in Current Directory Recursively

```bash
mcpidl ./...
```

### Process All Files in Specific Directory Recursively

```bash
mcpidl test/...
```

## IDL Syntax

### File Structure

```idl
go_package = "package_name"

// Define reusable data types
data data_type_name {
    field_name: type "Field description" [required]
    // More fields...
}

// Tool definition
tool tool_name {
    description "Tool description"
    
    input {
        field_name: type "Field description" [required]
        // More fields...
    }
    
    output {
        field_name: type "Field description"
        // More fields...
    }
}

// Additional tools...
```

### Data Type Definitions

```idl
// Define a simple data type
data system {
    curr_app: string "Current application" required
    version: string "Version" required
    is_active: bool "Is active"
}

// Define a data type with nested data reference
data user_info {
    user_id: string "User ID" required
    user_name: string "User name" required
    system_info: system "System information" required
    settings: object "User settings" required
}
```

### Tool Definition

```idl
tool GetUserInfo {
    description "Get user information"

    input {
        user_id: string "User ID" required
    }

    output {
        success: bool "Whether the operation succeeded"
        error_message: string "Error message if operation failed"
        user_info: user_info "User information" required
    }
}
```

### Supported Types

- **Scalar Types**: `string`, `int`, `int64`, `float64`, `bool`
- **Object Type**: `object` (converted to `map[string]any`)
- **Array Types**: `[string]`, `[int]`, `[object]`, etc. (converted to `[]string`, `[]int`, `[]map[string]any`, etc.)
- **Data Type References**: Reference previously defined data types

### Field Modifiers

- **required**: Mark a field as required (non-required fields are generated as pointer types)

## Example

### Input IDL File (`example.mcp`)

```idl
go_package = "main"

// Define data types
data System {
    currApp: string "当前app" required
    version: string "版本号" required
    isActive: bool "是否激活"
}

data UserInfo {
    userId: string "用户ID" required
    userName: string "用户名" required
    email: string "邮箱"
    phone: string "手机号"
    systemInfo: System "系统信息" required
    settings: object "用户设置" required
    tags: [string] "用户标签"
}

// Define tools
tool GetUserInfo {
    description "Get user information"

    input {
        userId: string "User ID" required
    }

    output {
        success: bool "Whether the operation succeeded"
        error_message: string "Error message if operation failed"
        userInfo: UserInfo "User information" required
    }
}
```
